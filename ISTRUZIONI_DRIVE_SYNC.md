# Dati di valutazione tra computer

Il nuovo strumento **Valutazione render** usa immagini locali e categorie create dall'utente. Non usa la precedente sincronizzazione Google Apps Script, legata a un elenco fisso di immagini.

Per passare a un altro computer o browser, clicca **Scarica progetto** nel primo computer. Nel secondo, clicca **Importa progetto**, poi apri la stessa cartella di immagini. Il file JSON contiene categorie, valutatori, assegnazioni, voti e note; le immagini non sono incluse.

**Valutazione veloce** ha un backup separato: usa **Scarica backup dei voti (JSON)** e **Importa voti**.
