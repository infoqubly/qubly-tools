# Pubblicazione QUBLY Tools

Il repository `infoqubly/qubly-tools` viene pubblicato automaticamente su GitHub Pages a ogni aggiornamento del ramo `main` tramite `.github/workflows/static.yml`.

Indirizzo: https://infoqubly.github.io/qubly-tools/

Le immagini di lavoro non fanno parte del sito. In Valutazione render e Valutazione veloce, scegli una cartella locale dopo aver aperto il sito. Categorie e voti rimangono nel browser; usa l'esportazione JSON per un backup o per spostarli su un altro computer.

Per controllare una pubblicazione, apri l'esecuzione più recente di `Deploy static tool to GitHub Pages` nelle Actions del repository e verifica il sito pubblico.
